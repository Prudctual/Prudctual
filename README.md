# Jasim Kareem

Basrah, Iraq · [github.com/Prudctual](https://github.com/Prudctual)

I build payment systems, APIs, and spend controls for AI agents. I keep the architecture small and easy to follow.

### Work

- **Agmoney:** A budget proxy between autonomous agents and LLM APIs so usage cannot run away.
- **SumerSend:** Webhooks for regional payment services (Zain Cash, AsiaHawala, FastPay, Qi Card), plus fixes for double-spend and authorization bugs.
- **Bank of Agents:** Wallets, human-approved transactions, and spending rules for multi-agent systems.

### Stack

- TypeScript, Node.js, Go, Python, Cloudflare Workers (Hono)
- FastAPI, Express, REST APIs, WebSockets, Redis, BullMQ, Docker
- PostgreSQL, Supabase, Prisma
- React, Vite, CSS
